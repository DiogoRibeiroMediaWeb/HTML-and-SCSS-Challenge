Olá isto é o meu primeiro desafio do estágion na MediaWeb e envolve html+scss

Este projeto envolve utilizar a root para criar classes essenciais e criar usefull classes para reutilizar codigo;
Ter um boa estrutura do trabalho e utilizar o flex tambem, se vires que é preciso mais que o flex, volta a rever;
A pagina é estatica, mas a navbar e o navmenu tem de estar sempre iguais, só o container principal é que pode ter scroll;

Passos do desenvolvimento:
- Começar por analisar o figma e ver as variaveis que podes retirar logo;
- Criar as variaveis e usefull classes;
- tirares uma print e analisares calmamente todos os containers que vais precisar(normalmente o figma tb ajuda);
- criar o html com uma classe highline a cor que tu quiseres para desenhares os conteiner e teres ja uma noção com o flex de  como vai ser cada container;
- a partir dai começar a desenvolver (!Dica mega Like Importantissima: quando desenvolves leva até ao fim o que estas a fazer! Frase de aprendizado: Mais vale ter tasks completas, do que ter 90% feito, mas sem nada finalizado);
- Tudo o que olhes e penses que podes reutilizar noutra parte do projeto cria a parte e não uma classe especifica para cada coisa, lembra-te que tens as usefull classes entre outras coisas que te podem ajudar a escrever menos código.
